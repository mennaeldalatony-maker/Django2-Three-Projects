# Professional Portfolio Showcase Platform

An ultra-fast, responsive developer portfolio built using **Django**, **Tailwind CSS**, and **Modular Static Assets (CSS & JS)**.

## 🛠️ Tech Stack & Architecture Highlights

* **Backend:** Python / Django (Views, Templates, Static File Management)
* **Frontend:** HTML5, Tailwind CSS (Dark Mode UI), JavaScript (`static/js/portfolio.js`)
* **Security:** Secure environment variables via `python-dotenv` (.env file hidden from Git repository)
* **Performance:** Lightweight static layout architecture with zero database overhead.
