# Codebreaker: Quantum Decryptor 🔐

Codebreaker: Quantum Decryptor is a cyberpunk logic puzzle game built using **Django**, **HTML5**, **Tailwind CSS**, and **JavaScript ES6+**.

## 🎮 Game Rules
- **Objective:** Guess the 4-color secret code within 8 attempts.
- **Green Beacon:** Correct color & correct position.
- **Yellow Beacon:** Correct color & wrong position.
- **Gray Beacon:** Incorrect color.

## 🚀 How to Run Locally

1. Clone repository & open in PyCharm.
2. Ensure Virtualenv is activated.
3. Run `python manage.py runserver` from PyCharm terminal or Run Configuration.
4. Access game in browser at: `http://127.0.0.1:8000/`
